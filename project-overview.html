What It Is

A two-part Next.js App Router site documenting the design and construction of a family home in Bengaluru, designed by Studio Anagami.

An anonymized case study covering vision, spaces, domains, materials, build journey, gallery, and lessons learned.

Data Flow

The repository is the only data door. All pages go through lib/repository.ts.

data/*.ts → lib/repository.ts → app/**/page.tsx ↓ lib/relations.ts

When DATA_SOURCE=api, the repository fetches from the FastAPI backend instead.

Architecture Rules

  1. Repository is the only data door. Pages never import from data/ directly.
  2. Relations are by ID, never by display name. Every cross-reference is an *Ids: string[] field, resolved at render time via lib/relations.
  3. Only render a link if its public page exists. Spaces/domains/lessons/gallery → clickable. Vendors/drawings/decisions → read-only chips.

Security Model

Supabase Auth (email/password) replaced the old browser-only password gate. The public site remains a static export on GitHub Pages — seed data ships in the bundle. Genuinely sensitive figures (negotiated prices, payment details) stay out of data/ entirely.
